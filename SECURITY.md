# Política de Segurança

## Versões suportadas

Apenas a versão mais recente publicada no npm (`brito-cli`) recebe correções de segurança.

## Como relatar uma vulnerabilidade

**Não abra uma issue pública.** Use um destes canais:

- [Relato privado de vulnerabilidade](https://github.com/wilsonbrito/brito/security/advisories/new) do GitHub (preferido).
- E-mail para **wilsonjb93@gmail.com**.

Inclua: descrição, passos para reproduzir, versão afetada e impacto estimado. Respondemos em até 7 dias e avisamos quando a correção for publicada.

## Escopo

Têm interesse especial: vazamento de chaves ou tokens, execução de comandos sem aprovação do usuário, falhas no lint de skills (injeção de prompt, `curl | sh`) e acesso indevido fora do diretório do projeto.
